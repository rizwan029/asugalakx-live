## Website structure

Static multi-page site (33 routes). Open `index.html` or serve the folder:

```bash
cd asugalakx-live && python3 -m http.server
```

| Route | Page |
|---|---|
| `/` | Homepage — hero, market pulse, today's brief, news, analysis, AI agents, ecosystem |
| `/markets/` | Market overview — tabs, sortable table, search, filter, watchlist |
| `/news/` | Newsroom + article pages |
| `/analysis/` | Market / technical / macro / on-chain research |
| `/crypto/` `/stocks/` `/forex/` | Dedicated market dashboards |
| `/web3/` | Web3 ecosystem map |
| `/ai-agents/` | 7 AI agents concept + intelligence pipeline |
| `/asgx/` `/asgx/tokenomics/` | ASGX token (proposed) + tokenomics |
| `/nft/` | NFT collection (proposed, 8,888 masks) + detail pages |
| `/character/` | NFT → 3D character pipeline concept |
| `/academy/` | Learning paths: Foundation / Intermediate / Advanced |
| `/community/` | Feed, discussion, trading journal, events |
| `/roadmap/` | 8-phase visual timeline |
| `/technology/` | Architecture diagram |
| `/whitepaper/` | 15-section documentation |
| `/about/` | Vision + brand philosophy |

Shared design system: `assets/css/style.css` · components: `assets/js/components.js` ·
data layer: `assets/js/data.js` · charts: `assets/js/charts.js`.
Cross-builder contract: `CONTRACT.md`.
